# GitHub Analytics Dashboard

Enter any GitHub username and get a live profile analysis: language breakdown,
top repositories by stars, recent-activity heatmap, and a follower trend — built
with **React** and **Recharts** against the **GitHub REST API**.

React + Recharts loaded from a CDN; the app is a small precompiled script, so
there's no bundler and no runtime transpile.

## Run

Open `index.html` in a browser. That's it — `app.js` is committed, so no build
is needed to run.

(If your browser blocks `fetch` from `file://`, serve the folder instead:
`python -m http.server` then open `http://localhost:8000`.)

Optionally paste a GitHub personal access token to raise the API limit from
60 to 5,000 requests/hour. It stays in your browser.

## Editing

The source lives in `app.jsx`. After changing it, recompile:

```bash
node build.mjs      # app.jsx -> app.js (fetches @babel/standalone, no npm install)
```

`build.mjs` transforms JSX only; modern browsers run the rest as-is. This keeps
the ~584 KB `@babel/standalone` and its main-thread transpile **out of the
browser** — page JS dropped from ~748 KB to ~174 KB gzip.

## Files

```
index.html   markup + design system (CSS) + deferred CDN + <script src=app.js>
app.jsx      source (edit this)
app.js       generated by build.mjs (committed so index.html runs as-is)
build.mjs    app.jsx -> app.js compiler
```

## Features

- **Language breakdown** — pie chart of primary languages across the user's repos.
- **Top repositories by stars** — horizontal bar chart.
- **Recent activity heatmap** — public push events over ~90 days.
- **Follower trend** — line chart built from snapshots saved per visit.
- **Rate-limit handling** — reads `X-RateLimit-*` headers, shows remaining quota,
  and gives a clear message with reset time on a 403.

## Honest API notes

The GitHub REST API cannot provide two of the "obvious" charts, so this app is
honest about it rather than faking data:

- **Contribution heatmap** — the full contribution graph is only in GitHub's
  *GraphQL* API. This uses the public **events** feed instead (~90 days, public
  pushes only).
- **Follower growth** — GitHub stores **no** follower history. The trend is built
  from `localStorage` snapshots taken each time you analyze a user, so it grows as
  you revisit. (First visit shows a single point.)

## Interview angles

- **Rate limiting** — a single `gh()` wrapper reads the rate headers, distinguishes
  404 / 401 / 403-rate-limit, and surfaces the reset time; a token switches to
  authenticated requests.
- **Data aggregation** — pure functions (`aggregateLanguages`, `topReposByStars`,
  `activityByDay`) transform raw API arrays into chart-ready series; unit-checked
  via `index.html?selftest` (asserts in the console).
- **Chart integration** — Recharts `ResponsiveContainer` for the three charts;
  the heatmap is a plain CSS grid (no chart lib needed for a calendar).

## Tech

React 18, Recharts, GitHub REST API, vanilla CSS. No bundler.

## Limitations

- Repos capped at the 100 most recent (no pagination).
- Language weighting is by repo count, not bytes (avoids one API call per repo,
  which would burn the rate limit).
